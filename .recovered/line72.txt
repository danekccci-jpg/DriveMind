## Setup Checklist

### Firebase Console Configuration

1. **Enable Email Link (Passwordless) sign-in**:
   - Go to **Firebase Console → Authentication → Sign-in method**
   - Enable **Email/Password** provider
   - Toggle ON the **"Email link (passwordless sign-in)"** checkbox beneath it.

2. **Add authorized domain for dynamic links**:
   - Go to **Firebase Console → Authentication → Settings → Authorized domains**
   - Ensure `drivemind.page.link` is listed (or your custom domain).

3. **Create a Firebase Dynamic Link** (if not already):
   - Go to **Firebase Console → Dynamic Links**
   - Create a new link prefix: `drivemind.page.link`
   - The deep link URL used in code is: `https://drivemind.page.link/login`

### AndroidManifest.xml — Intent Filter for Deep Links

Add this inside the `<activity>` tag of your main activity in `android/app/src/main/AndroidManifest.xml`:

```xml
<!-- Firebase Email Link deep link handler -->
<intent-filter android:autoVerify="true">
    <action android:name="android.intent.action.VIEW" />
    <category android:name="android.intent.category.DEFAULT" />
    <category android:name="android.intent.category.BROWSABLE" />
    <data
        android:host="drivemind.page.link"
        android:scheme="https" />
</intent-filter>
```

**Placement**: This should be added inside the `<activity android:name=".MainActivity" ...>` block. If using Expo with the config plugin, it's auto-generated in the `withDriveMindNative.js` plugin's `withAndroidManifest` section.

### firebase.json — Hosting Rewrites (for web fallback)

If you use Firebase Hosting for the `authDomain`, add to your `firebase.json`:

```json
{
  "hosting": {
    "rewrites": [
      {
        "source": "/login",
        "dynamicLinks": true
      }
    ]
  }
}
```

**Placement**: Root of your Firebase project alongside `firestore.rules`, etc.

### Firebase CLI Commands

```bash
# Deploy updated hosting config (if changed firebase.json)
firebase deploy --only hosting

# No CLI commands needed for Email Link auth — it's console-only config
```
